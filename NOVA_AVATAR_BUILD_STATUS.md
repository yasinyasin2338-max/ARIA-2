# Nova Avatar — clean build track

This branch contains a new from-scratch Android implementation track for the Persian text-controlled virtual character app.

Current stage: **development build, not final**.

Implemented source includes a local Persian parser/action queue, RTL text UI, OpenGL ES 3 apartment renderer, and a procedural 3D development humanoid rig used only as an engineering placeholder.

The final fixed-identity realistic 3D character asset is **not yet claimed complete**. Original real photos remain the authoritative identity reference; generated character sheets are secondary references only. No runtime face regeneration is part of the architecture.
